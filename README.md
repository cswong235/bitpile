# ![bitPile logo](./src/assets/BitPile.png)

A project built to let people store their own favourite games.

![Project Screenshot](./src/assets/Mission5.png)

Features include:
- Game carousel with detailed game cards
- Game count
- Filtering options
- Game addition module

Built with:
- JavaScript (ES6)
- React
- HTML
- CSS
- Bootstrap
